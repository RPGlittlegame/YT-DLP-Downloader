# YT-DLP Downloader

基于 `yt-dlp` 和 `CustomTkinter` 构建的现代化跨平台视频下载器。

## 🌟 核心特性

- **现代化交互界面**: 采用类似 MacOS 的清爽设计和深色模式，UI 布局紧凑。
- **动态解析与智能选择**: 一键解析链接，动态获取并提供所有可用的视频和音频轨道选项。
- **自定义下载与格式转换**:
  - 灵活组合视频和音频画质/音质。
  - 支持丰富的输出封装格式：`MP4`, `MKV`, `AVI`, `WMV`, `MOV`, `MP3`。
- **安全的 Cookie 管理机制**: 支持导入 `cookies.txt` 文件并自动备份至本地专属目录，方便后续在下拉菜单中直接选择，轻松下载会员或受限内容。
- **实时进度反馈**: 底部配有进度条和滚动日志，随时掌握下载状态与速度。

## 💻 快速开始（全平台开箱即用）

本项目已针对 **Windows / macOS / Linux** 进行全平台开箱即用优化。安装 Python 依赖即可自动具备 FFmpeg 音视频合并能力，无需手动配置环境变量。

### 第一步：克隆/下载并安装依赖

确保电脑已安装 **Python 3.8+**，打开终端或命令行执行：

```bash
# 推荐创建并激活虚拟环境 (可选)
python3 -m venv venv
source venv/bin/activate  # macOS / Linux
# 或 .\venv\Scripts\activate (Windows)

# 一键安装所有依赖 (包含自动适配各操作系统的静态 FFmpeg)
pip install -r requirements.txt
```

> **提示**：Linux 用户若使用系统 Python，需确保已安装 Tkinter 支持组件（如 Ubuntu/Debian 执行 `sudo apt install python3-tk`）。

### 第二步：启动软件

依赖安装完成后，直接运行即可：

```bash
python main.py
```

*说明：程序启动时会自动检测并优先使用项目内置 `bin/`、`imageio-ffmpeg` 免安装静态引擎或系统全局 `PATH` 中的 FFmpeg。*

## 🚀 软件使用步骤

启动软件后，您可以按照以下流程进行下载：

1. **输入视频链接**: 将网页上的视频 URL 粘贴至顶部的输入框中。
2. **解析视频信息**: 点击 **[解析]** 按钮。等待片刻，软件会获取该视频的可用画质和音质选项，并在界面上方显示视频标题。
3. **自定义下载选项**:
   - **视频与音频选择**: 在下拉菜单中选择您需要的视频清晰度和音频质量（或选择仅音频/仅视频）。
   - **格式选择**: 切换您希望保存的最终格式（如 MP4, MKV, AVI, WMV, MOV, MP3 等）。
   - **选择保存位置**: 点击 **[选择目录]** 设定视频保存的本地文件夹。
   - **配置 Cookie (按需)**:
     - 如果您要下载需要登录才能观看的内容（如会员视频），请先通过浏览器插件导出 `cookies.txt`。
     - 在软件中点击 **[导入 Cookie]** 按钮加载该文件。软件会自动将其拷贝到安全的本地项目目录中统一管理，以后您可以直接从左侧下拉菜单中选择已导入的 Cookie。
4. **开始下载**: 确认配置无误后，点击底部的 **[开始下载]** 按钮。您可以在下方的进度条和日志窗口中实时观察下载进度、速度以及预估剩余时间。
