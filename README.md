# YT-DLP Downloader

基于 `yt-dlp` 和 `CustomTkinter` 构建的现代化跨平台视频下载器。

## 🌟 核心特性

- **现代化交互界面**: 采用类似 MacOS 的清爽设计和深色模式，UI 布局紧凑。
- **动态解析与智能选择**: 一键解析链接，动态获取并提供所有可用的视频和音频轨道选项。
- **自定义下载与格式转换**: 
  - 灵活组合视频和音频画质/音质。
  - 支持丰富的输出封装格式：`MP4`, `MKV`, `AVI`, `WMV`, `MOV`, `MP3`。
- **安全的 Cookie 管理机制**: 支持导入 `cookies.txt` 文件并自动备份至本地专属目录，方便后续在下拉菜单中直接选择，轻松下载会员或受限内容。
- **实时进度反馈**: 底部配有进度条和滚动日志，随时掌握下载状态与速度。

## 💻 新电脑安装与配置指南

若您在一台全新的电脑上运行此源码，请严格按照以下步骤操作：

### 第一步：环境准备
1. 确保您的电脑已安装 **Python 3.8** 或更高版本。
2. **下载源码**: 将本项目的所有文件下载或克隆到您的本地文件夹中。
3. **打开终端并定位**:
   - **Windows**: 在项目文件夹的空白处，按下 `Shift` 键并右键点击，选择“在此处打开 PowerShell 窗口”或“在此处打开终端”。
   - **macOS/Linux**: 打开终端（Terminal），使用 `cd` 命令进入到项目所在的文件夹目录。
4. **安装依赖库**: 在打开的终端窗口中，输入并运行以下命令：
   ```bash
   pip install -r requirements.txt
   ```
   *提示：如果安装速度较慢，可以尝试使用镜像源，例如 `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`*

### 第二步：配置 FFmpeg (关键依赖)
由于本软件在合并音视频轨道及格式转换时依赖外部工具 FFmpeg，因此必须进行配置：
1. **创建目录**: 在项目根目录下，新建一个名为 `bin` 的文件夹。
2. **下载 FFmpeg**:
   - **Windows 用户**: 前往 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载 `ffmpeg-release-essentials.zip`。
   - **macOS 用户**: 下载静态编译好的 [FFmpeg 二进制文件](https://evermeet.cx/ffmpeg/)。
3. **放置文件**:
   - 解压下载的压缩包。
   - 将其中的 `ffmpeg.exe` (Windows) 或 `ffmpeg` (Mac) 可执行文件复制并粘贴到刚刚创建的 `bin` 文件夹中。

### 第三步：启动软件
确认 `bin/ffmpeg` 已正确放置后，在刚才打开的终端中执行以下命令启动图形界面：
```bash
python main.py
```

## 🚀 软件使用步骤

启动软件后，您可以按照以下流程进行下载：

1. **输入视频链接**: 将网页上的视频 URL 粘贴至顶部的输入框中。
2. **解析视频信息**: 点击 **[解析]** 按钮。等待片刻，软件会获取该视频的可用画质和音质选项，并在界面上方显示视频标题。
3. **自定义下载选项**:
   - **视频与音频选择**: 在下拉菜单中选择您需要的视频清晰度和音频质量（或选择仅音频/仅视频）。
   - **格式选择**: 切换您希望保存的最终格式（如 MP4, MKV, AVI, WMV, MOV, MP3 等）。
   - **选择保存位置**: 点击 **[选择目录]** 设定视频保存的本地文件夹。
   - **配置 Cookie (按需)**: 
     - 如果您要下载需要登录才能观看的内容（如会员视频），请先通过浏览器插件导出 `cookies.txt`。
     - 在软件中点击 **[导入 Cookie]** 按钮加载该文件。软件会自动将其拷贝到安全的本地项目目录中统一管理，以后您可以直接从左侧下拉菜单中选择已导入的 Cookie。
4. **开始下载**: 确认配置无误后，点击底部的 **[开始下载]** 按钮。您可以在下方的进度条和日志窗口中实时观察下载进度、速度以及预估剩余时间。
