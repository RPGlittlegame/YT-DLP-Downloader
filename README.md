# YT-DLP Downloader

基于 `yt-dlp` 和 `CustomTkinter` 构建的现代化、高性能且安全的跨平台视频下载器。

---

## 🌟 核心特性

- **现代化自适应界面**:
  - 采用类似 macOS 的精致设计，完美支持深色/浅色模式切换；
  - **弹性响应式布局**：窗口上下压缩时，日志框支持自动折叠收缩，确保下载按钮、进度条及核心控制区在任何极限尺寸下均完整可见；
  - **便捷交互**：URL 输入框支持回车（`Enter` / `Return`）一键解析，操作一气呵成。
- **播放列表与合集灵活下载**:
  - 智能识别 YouTube 等平台的 Playlist/合集/选集；
  - 支持全选、区间选择（如 `1-5,8`）或勾选指定单集，提供独立分集下载进度实时反馈。
- **企业级安全性与防御性设计 (Defense-in-Depth)**:
  - **路径穿越防御**：清理分块临时文件时强制执行 `Path.resolve()` 规范化校验，严格限制删除范围，杜绝意外越界删文件风险；
  - **非阻塞优雅生命周期**：关闭窗口时自动通知取消后台下载，采用异步轮询机制平稳等待子进程与网络流安全退出，彻底避免“界面卡死”或“孤儿进程”；
  - **并发与防重入锁**：针对解析与下载行为提供状态锁保护，防止用户连击造成资源竞争。
- **智能依赖管理 (System-First)**:
  - 优先无感接入系统已有 FFmpeg（零额外体积开销）；
  - 缺失时提供现代化指引，支持**一键全自动下载并校验静态引擎**，或手动指定本地文件与复制系统包管理器命令；
  - 执行 `ffmpeg -version` 闭环校验，确保二进制文件的真实可执行性。
- **双轨分发体系**:
  - **Slim 精简版 (~15MB)**：体积轻巧，适合成熟环境与快速网络分发；
  - **Full 完整版 (~50MB)**：内置离线 FFmpeg 引擎，100% 开箱即用。
- **智能断点续传**: 下载中断或取消时自动保留 `.part` 分块文件，下次下载无缝续传。
- **全格式转码与画质自由定制**:
  - 自由组合视频分辨率（最高支持 4K/8K）与高码率音频轨道；
  - 支持丰富的输出封装格式：`MP4`, `MKV`, `AVI`, `WMV`, `MOV`, `MP3`；
  - 智能容量预估：切换清晰度时实时计算预计文件大小。
- **结构化错误识别与排查提示**: 自动捕获 `yt-dlp` 异常，智能提炼 403 Forbidden、会员/私享视频、Cookie 失效、Bot 验证等常见错误，提供通俗易懂的修复指引。
- **安全的 Cookie 管理机制**: 支持导入 `cookies.txt` 文件并自动备份至本地专属目录，方便后续直接在下拉菜单中选用，轻松下载会员或受限内容。

## 💻 快速开始

### 1. 环境准备与依赖安装

确保电脑已安装 **Python 3.8+**，在终端或命令行中执行：

```bash
# 创建并激活虚拟环境 (推荐)
python3 -m venv venv
source venv/bin/activate  # macOS / Linux
# 或 .\venv\Scripts\activate (Windows)

# 安装轻量核心依赖 (约 35MB)
pip install -r requirements.txt
```

> **提示**：Linux 用户若使用系统原生 Python，需确保已安装 Tkinter 支持（如 Ubuntu/Debian 执行 `sudo apt install python3-tk`）。

### 2. 启动软件

```bash
python main.py
```

*说明：程序启动时会自动检测环境中的 FFmpeg。若尚未配置，可在右上角点击徽章打开向导，一键自动下载并配置。*

## 🚀 软件使用流程

1. **输入视频链接**: 将视频或播放列表 URL 粘贴至顶部输入框，直接敲击键盘 **`Enter` 回车键**（或点击 **[解析]** 按钮）。
2. **选择音视频轨与格式**:
   - **画质/音质选择**: 在下拉菜单中选择您需要的分辨率与音质（支持仅下载音频或仅下载视频）；
   - **封装格式**: 切换需要保存的目标格式（如 `MP4`、`MKV`、`MP3` 等）；
   - **播放列表模式**: 若解析为合集，可自由选择“全部下载”、“区间下载”或“手动勾选单集”；
   - **保存目录**: 点击 **[选择目录]** 设定保存路径。
3. **配置 Cookie (按需)**:
   - 下载需要登录或受限的内容（如 Bilibili/YouTube 会员视频）时，可通过浏览器插件导出 `cookies.txt`；
   - 点击 **[导入 Cookie]**，软件会自动安全备份，之后可直接从下拉菜单中调用。
4. **开始下载**:
   - 点击底部的 **[开始下载]** 按钮；
   - 底部进度条与状态标签将实时同步下载进度、速度与剩余时间，日志区提供清晰的阶段反馈。

## 🛠️ 打包与双轨构建 (Build)

本项目提供了跨平台的一键双轨构建脚本 `build.py`：

```bash
# 1. 构建 Slim 精简版 (约 15MB，推荐)
python build.py --edition slim

# 2. 构建 Full 离线完整版 (约 50MB，内置静态 FFmpeg)
python build.py --edition full

# 3. 指定参数构建 (例如跳过归档压缩)
python build.py --edition slim --no-zip
```

打包产物将自动输出并归档于 `dist/` 目录下（如 macOS 的 `.dmg` 或 Windows 的 `.zip`）。
