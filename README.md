z# YT-DLP Downloader

一个简单、好用、界面好看的跨平台视频/音频下载工具。无需复杂的命令行操作，粘贴链接就能一键下载高清视频或提取 MP3 音频。

---

## ✨ 软件特色功能

- 🎬 **画质随心选**：支持 4K / 2K / 1080P / 720P 等多种清晰度，支持单独提取 MP3 / M4A 高清音频。
- 📦 **格式自由转**：支持输出为 MP4、MKV、AVI、MOV、WMV 视频格式及 MP3 音频。
- 📋 **合集/播放列表批量下载**：自动识别合集视频，支持一键全部下载、按序号范围下载（如 `1-5,8`）、或手动勾选想看的单集。
- 🎨 **极简自适应界面**：支持一键切换深色/浅色模式；界面窗口缩小拉扁也不会遮挡进度条和下载按钮。

- 🍪 **会员/受限内容支持**：支持一键导入浏览器导出的 `cookies.txt`，轻松下载需要登录才能观看的高清或会员视频。
- ⏸️ **支持断点续传**：网络中断或暂停后，再次下载直接从断点继续，省时省流量。
- 💡 **贴心的错误提示**：遇到视频无法下载时，软件会自动提供通俗易懂的解决建议（如提示需要登录或地区受限）。

## 📖 新手使用教程（三种版本如何选择与使用）

提供了三种使用方式，请根据你的需求选择最适合的一种：

```
                    ┌──────────────────────────────┐
                    │     我该选择哪种版本？       │
                    └──────────────┬───────────────┘
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
   【Full 完整版】            【Slim 精简版】           【源代码运行版】
   适合：完全不想折腾         适合：想要软件体积小      适合：开发者 / 想要自己
   下载解压直接就能用         首次打开点一下自动安装    二次修改与运行源码
   （体积约 80MB）            （体积仅约 15MB）         （需要 Python 环境）
```

---

### 方案 A：Full 完整版（最省心，100% 离线即开即用）

> **适合人群**：新手小白，不想做任何额外配置，下载解压就能直接用。

1. **下载与解压**：下载打包好的 `Full` 完整版压缩包，解压到任意文件夹。
2. **打开软件**：
   - **Windows**：双击运行 `YT-DLP_Downloader.exe`
   - **macOS**：双击运行 `YT-DLP_Downloader.app`（若提示未知开发者，前往「系统设置」->「隐私与安全性」点击「仍要打开」即可）
3. **开始下载**：
   1. 复制你想下载的视频网页链接（如 Bilibili、YouTube 等）；
   2. 粘贴到软件顶部的输入框，直接按键盘 **Enter 回车键**（或点击 **[解析]**）；
   3. 挑选你想要的分辨率（如 1080P）和保存格式（如 MP4）；
   4. 点击右侧 **[选择目录]** 挑一个保存位置；
   5. 点击底部的 **[开始下载]** 按钮，等待进度条走完即可！

---

### 方案 B：Slim 精简版（超轻巧，体积仅 15MB）

> **适合人群**：想要下载速度更快、不占磁盘空间的用户。
> *注：Slim 版无需安装 Python，只有在电脑没有视频合并引擎时，首次打开在软件里点一下即可自动配好。*

1. **下载与打开**：下载并解压 `Slim` 精简版，直接双击运行程序。
2. **首次依赖检查（仅需点一次）**：
   - 软件启动时会自动检查电脑里是否有视频合并引擎（FFmpeg）；
   - 如果没有，软件右上角会显示提示，点击它会弹出设置窗口；
   - 点击窗口里的 **【一键自动下载并配置】** 按钮，软件会在几十秒内自动完成配置，之后即可永久正常使用。
3. **日常使用**：
   - 按照「方案 A」的步骤，粘贴链接 ➜ 回车解析 ➜ 选择画质 ➜ 点击下载。

---

### 方案 C：源代码版（开发者 / 想要直接跑 Python 源码）

> **适合人群**：电脑上已安装 Python 环境，想要通过命令行直接启动或二次开发的用户。

1. **安装依赖**：
   打开终端（Terminal / CMD / PowerShell），进入项目文件夹，执行以下命令安装运行所需的库：

   ```bash
   pip install -r requirements.txt
   ```

2. **启动软件**：

   ```bash
   python main.py
   ```

3. **自己动手打包（可选）**：
   如果你想把修改后的代码重新打包成无需 Python 环境的单文件程序，只需运行：

   ```bash
   # 打包 Slim 精简版
   python build.py --edition slim

   # 打包 Full 完整版（需本地具备 ffmpeg）
   python build.py --edition full
   ```

   打包好的程序会自动出现在 `dist/` 文件夹中。
